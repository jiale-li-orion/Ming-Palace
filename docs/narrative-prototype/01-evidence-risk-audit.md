# 第一步：证据与风险审计

> 项目：“精游”南京明故宫遗址朱允炆叙事纵切片  
> 版本：v0.6（依据第五步最终台词反向校正版）  
> 修订：2026-07-26，统一路线、互动、口语术语与史源边界  
> 目标：判断现有材料是否足以支撑一段 6—8 分钟、两个主要空间节点的第一人称在场叙事；不是台词稿。

## 一、审计结论

### 1. 当前可以继续使用朱允炆

[A] 朱允炆与南京明宫具有其他明代皇帝不具备的完整关系：他在这里出生、成长、即位执政，并在南京失守、统治终结时消失于可确认的历史记录。

[B] 因而，他是唯一能够用个人经历串联南京明宫居住、教育、礼仪、行政、决策和政权终局等功能的明代皇帝。

现有材料已经足以支撑一个克制的 6—8 分钟原型，理由不是“失踪传奇”，而是已经形成两条可落到现场的证据链：

1. 奉天门指向奉天殿：殿试中，文章、相貌与政治立场共同进入了人物判断；
2. 午门及其改名：经典、名分与礼制被用于安排政治秩序，却不能自动解决执行、军事和止损问题。

### 2. 当前不能写成完整人物传记

材料仍不足以支撑：

- 连续、细密的私人心理史；
- 有具体动作、对话和生活习惯的童年回忆；
- 对建文四年宫城终局的逐分钟复原；
- 对朱允炆逃亡、出家或死亡方式的任何确认；
- 把某座“便殿”精确钉在今日地面上的确定位置。

因此，本原型只能围绕“文字如何成为判断和秩序，又在哪里失效”展开，不能扩写为“朱允炆的一生”。

## 三、必须确认的明故宫空间关系

### 1. 本原型必须成立的空间链

`奉天殿方向（不可见） → 奉天门遗址 → 内五龙桥 → 午门北侧 → 午门城台 → 午门南侧`

必须确认：

1. 奉天门遗址的准确范围、北侧入口及安全停留点；
2. 奉天殿、奉天门、内五龙桥和午门沿宫城正中御道次第展开的空间关系；
3. 用户能否在第一节点安全转身北望，再向南穿过奉天门；
4. 奉天门至内五龙桥、再至午门北侧的真实步行距离与路面状态；
5. 午门城台开放时段、入口、上下楼方式、单向或双向通行规则；
6. 城台上是否存在可安全连续北望的停留区域；
7. 用户能否下楼后向南穿过午门，到达南侧安全回望点；
8. 雨天、拥挤、封楼或施工时的地面替代路线。

### 2. 可以复原但不能假装精确的空间

- 奉天殿：可以从奉天门指向其方向；不可让用户误以为殿基就在奉天门遗址上。
- 文楼、武楼：可以在午门城台北望画面中作为宫城制度空间的一部分复原。
- “便殿”：只能作为功能性空间概念，不得未经互证等同于文楼、省躬殿或某一新建宫殿。
- 省躬殿：方孝孺《省躬殿铭》记其在乾清、坤宁二宫之间，属于朱允炆的重要个人空间；但不在本次南侧短线内强行落点。
- 现代东西向道路：可以说它横在奉天门与奉天殿旧址之间，切开了原本相连的宫城空间；不能据此声称奉天殿遗址边界已经精确复原，也不能说文楼确定就在今天某一段路面正下方。

### 3. 路线含义的边界

[C] 这是一条从宫城内部向外退出的反向路线。

[D] 它不是朱允炆在建文四年的逃亡路线，不能用用户的南行暗示人物确曾如此出逃。

## 四、最容易落入野史或虚构的危险点

### 高危：一律不得进入人物亲历

1. 朱允炆从地道出逃、出家、流亡云南或海外、晚年回归等传说；
2. 确认其死亡时间、地点、身份或墓葬；
3. 把建文帝出亡传说写成他的回忆；
4. 把宫城大火写成他亲自纵火、目睹某一具体人物死亡或沿特定路线逃走；
5. 为戏剧效果补写与方孝孺、黄子澄、齐泰之间的完整私密对话；
6. 补写童年在宫中的日常习惯、母亲或师长对其性格的具体影响；
7. 使用“长于深宫妇人之手”等无直接证据且带性别偏见的性格归因。

### 中高危：可讨论，但必须降级

1. 王艮因貌被降、胡广因仪貌和策论获第一：不是只见于清修《明史》或一条孤立晚出笔记，而是明代《双槐岁钞》《姜氏秘史》及后续多书承载的解释传统；证据强度应提升，但因诸书可能承袭、又非建文二年现场记录，仍按 `[B]` 使用；
2. “毋使朕有杀叔父名”：后出史书对命令的概括，不是原诏逐字文本；
3. 《姜氏秘史》“处便殿，弄柔翰而已”：作者讥评，不是现场实录；
4. 《明史》中的东角门问策、削燕犹豫等完整对话：可作为人物索引，不能冒充速记；
5. 朱元璋与朱标在文楼讨论七国之乱：现存《太祖实录》经过永乐朝改修，且与宗藩正当性争论高度呼应，本原型删除；
6. 朱允炆“几乎从未离开宫城”：可以说其主要生活和政治生涯在此，不说字面意义的“从未离开”。

### 认识论危险

- 把“方孝孺所写”直接等于“朱允炆内心所想”；
- 把诏书中的公开政治人格直接等于私人性格；
- 用后来的王艮死节、胡广仕永乐反证朱允炆当年的判断；
- 因李景隆未被杀、宗王受到宽待，就把朱允炆定义为现代“和平主义者”；
- 把经典政治讽刺成单纯书呆子行为，忽略名分、礼制在明初政治中的现实效力；
- 反过来因其理想主义而替他免除削藩、用人及战争责任。

### 只能交给中性史官层、字幕或研究注释

- 王艮、胡广在建文朝终结后的不同选择；
- 《姜氏秘史》的成书年代、作者位置和讥评语气；
- 《太祖实录》《太宗实录》的改修、编纂和史源风险；
- 文楼、武楼、便殿与现代道路的未定空间关系；
- 朱允炆失踪后的各种传说；
- 宫城在数百年间毁坏的完整过程；
- “朱允炆是唯一完整串联宫城功能的明帝”这一跨朝代比较结论。人物可以说自己的经历，但不能替后世完成全体明帝比较。

## 六、转向钱谦益的明确门槛

### 1. 立即转向的硬门槛

出现以下任一情况，应停止为朱允炆补写，不再用文学语言掩盖：

1. 无法可靠证明朱允炆与南京明宫具有出生、成长、执政、统治终结四阶段中的至少三项，或“宫城是其主要生活世界”不能成立；
2. 奉天殿殿试和午门改名两条主证据链中，有一条经核验后整体失效，而又找不到同一现场的替代 A 级事件；
3. 两个主要节点都只能依赖后出笔记、传说或 B/C 级心理推断，没有现场硬锚；
4. 要使人物成立，必须确认其逃亡、出家或死亡传说；
5. 每段第一人称独白中，历史陈述超过一半只能标为 `[待核验]` 或依赖叙事补写；
6. 现场勘测证明奉天门—午门路线无法安全运行，且不存在保持核心空间意义的替代路线。

### 2. 触发重写而非立即换人的门槛

出现以下情况先删减，不立即换钱谦益：

- 若发现《双槐岁钞》《姜氏秘史》与后续诸书只是同一错误源的机械承袭，且无其他支持：保留殿试、赐名和最终名次，把仪貌与策论原因移至研究注；
- “便殿”无法定位：保留午门改名和礼制主线，删除文楼定点；
- 完整登楼导致时长超限：改为地面北望方案，或将产品总时长调整为 9—10 分钟；
- “慎杀”证据链不足：删除性格判断，只保留诏书中的亲亲语言与实际战争行动。

### 3. 当前判定

当前尚未达到转向钱谦益的门槛。朱允炆已经具备：

- 唯一且强烈的“人物—宫城”关系；
- 两个能够落到现实地点的叙事支点；
- 足够形成矛盾而非洗白的人物责任；
- 一条不依赖失踪传奇的体验路线。

但这只证明他适合当前纵切片，不证明足以独立支撑一条长线路。

## 八、第一步最终结论

朱允炆可以继续，不因材料稀少自动转向钱谦益；但可写范围必须严格限制在：

`文章与人物判断 → 名制与现实秩序 → 皇帝责任 → 宫城与个人存在`

一旦需要依靠失踪传说、私密童年或确定逃亡路线才能制造戏剧性，就说明本人物方案已经越过证据边界。
