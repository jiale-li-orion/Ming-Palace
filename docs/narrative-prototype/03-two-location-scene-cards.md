# 第三步：两个空间节点的场景卡

> 项目：“精游”南京明故宫遗址朱允炆叙事纵切片  
> 版本：v0.6（依据第五步最终台词反向校正版）  
> 修订：2026-07-26，统一正中御道、两支互动与实际文本预算  
> 主节点：奉天门遗址、午门复合节点  
> 过渡空间：内五龙桥  
> 说明：午门北侧、城台和南侧属于同一复合节点，不另算第三个主节点。

## 总路线

`奉天门北侧入口 → 奉天门遗址 → 内五龙桥 → 午门北侧 → 登午门城台 → 北望 → 下城台 → 向南穿午门 → 午门南侧回望`

路线整体由宫城内部向外退出。

[D] 不得把这条路线解释为朱允炆在建文四年的逃亡路线。

## 场景卡一：奉天门遗址

### 1. 基本信息

| 项目 | 内容 |
|---|---|
| 现实位置 | 奉天门遗址及其北侧可安全停留区域 |
| 历史指向 | 北侧已消失的奉天殿 |
| 用户动作 | 到达、停下、北望或转身指认、观察绘画复原、再向南穿过奉天门 |
| 主要时长 | 有声约 55—65 秒，另含 5 秒明确停顿 |
| 固定独白 | 第一段 |
| 关系阶段 | 陌生后来者 → 现场见证者 |
| 核心问题 | 一篇文章能不能代表一个人？ |

### 2. 为什么必须在这里发生

[A] 建文朝唯一一次殿试在奉天殿举行。

[A][B][C] 奉天殿、奉天门、内五龙桥和午门原沿宫城正中的御道次第展开；在第一节点只需由奉天门指向北侧奉天殿方向。

[C] 今日奉天殿不可见，奉天门成为用户在现实中能够站定、并指向那次判断发生之处的入口。

重要边界：

- 不能说殿试发生在奉天门；
- 不能把奉天门说成朱允炆的专属日常听政地点；
- 场景意义来自“现实门址通向不可见殿宇”，而不是硬造奉天门个人事迹。

### 3. 历史锚点

必须保留：

- [A] 建文二年殿试；
- [A] 最终胡广第一、王艮第二、李贯第三；“赐名靖”保留在研究注，不进入当前有声稿；
- [A][B] 《双槐岁钞》《姜氏秘史》及后续多书称王艮奏策／对策原居第一；这不是只见于《明史》的孤立晚说；
- [B] 明代多种记载以王艮相貌、胡广仪貌及其策论对宗藩问题的立场解释名次变化；诸书可能承袭，不据此确定两个因素的先后、权重或唯一因果。

必须删除：

- 王艮后来死节、胡广后来仕永乐；
- 朱允炆因后来的结局向王艮道歉；
- 胡广与李景隆都因外表好而获用的类比；
- “朱允炆一贯以貌取人”的性格结论。

### 4. 叙事任务

这一场不讲科举制度，而是让朱允炆面对一次自己作出的排序：

1. 纸面上，王艮的文章居前；
2. 排名时，人的外表和政治立场进入判断；人物可以概括承认这两类因素，但不复述一条确定、完整的内心因果链；
3. 皇帝试图从文字认识一个人，却又不相信文字已经足够；
4. 这次矛盾成为第二节点“以文字和名分安排国家”的局部预演。

人物在这一场只能承认判断的复杂和有限，不能用后来结局完成道德自判。

### 5. 现实视觉层

- 奉天门遗址石构、地面轮廓和周边现代景观；
- 用户当前所站位置与北侧方向；
- 现实中奉天殿的缺失。

### 6. 绘画复原层

- 以固定绘画场景显示奉天门沿宫城正中御道通往奉天殿的空间关系；
- 奉天殿不必完整照片级复原，可用廊庑、殿基、殿身和人群的分层笔触表达；
- 殿试画面只表现空间、座次、卷面与最终名次，不演出无证据的朱允炆与王艮、胡广私下对话；
- 对排序原因采用文字层、视线或构图暗示，不演成确定历史现场。

### 7. 声音

- 开始时先让现实环境声存在数秒；
- 第一段独白为当前第五步的 189 个有声净字，按 200—220 字／分钟约 52—57 秒，另留 5 秒明确停顿；
- 句子短，避免科举背景连续解释；
- 结尾只给出向南行走的邀请，不做主题总结。

### 8. 场景转折

[C] 人物从“我曾在纸上给人排次序”，转向“后来，我也试图用纸上的名分给整个世界排次序”。

用户随后向南穿过奉天门。空间动作本身完成从“殿试判断”到“政治秩序”的转场。

### 9. 风险和兜底

- 若北侧无法安全停留，改在奉天门遗址内部或南侧安全点，通过画面箭头指向北方；
- 若现场噪声过大，首句不得依赖细小环境音；
- 空间触发失败时使用“我已到达奉天门”按钮或开发者触发；
- 不能为了让奉天殿“可见”而宣称精确 AR 对齐已完成。

## 过渡卡：奉天门—内五龙桥—午门

### 1. 功能

这不是第三个叙事节点，而是一段把空间史、个人生活世界和午门改名连接起来的行走。

[C] 用户从奉天殿所在的政治核心向宫门退出，人物也从一次具体的名次判断，过渡到一套更大的礼制与政治秩序。

### 2. 声音规则

- 不新增科普段，但保留第五步已经确定的三项内容：宫城正中御道的建筑序列、现代道路对旧宫空间的切开、朱允炆在宫城中出生至统治终结的连续关系；
- 到达午门北侧后，在登楼前完成“午门改端门—《周礼》—大同与天下安宁和睦”的设定；
- 当前有声净字为 226 字，另保留 8—12 秒无语音行走；该段实际需约 70—80 秒，不得仍按“25 秒语音”排期；
- 内五龙桥只作空间阈限，不强行绑定朱允炆个人事件；
- 如果需要方向确认，采用低存在感提示，不持续显示按钮。

### 3. 视觉规则

- 现实层保持优先；
- 可用一张缓慢展开的绘画长卷，表现奉天门、内五龙桥和午门沿宫城正中御道次第展开；
- 现代东西向道路应表现为横在奉天门与奉天殿旧址之间、切开原有宫城空间；不把尚未精确的遗址边界画成测绘定论；
- 画面不连续追踪用户位置，不伪装实时三维定位；
- 中山东路等现代切割应具体呈现，不用“沧海桑田”代替。

### 4. 安全

- 行走中不触发需要选择的互动；
- 过路口、人流密集或路面复杂时停止叙事视觉；
- 实际步行时长必须计入 6—8 分钟总时长。

## 场景卡二：午门复合节点

### 1. 基本信息

| 项目 | 内容 |
|---|---|
| 现实位置 | 午门北侧、午门城台、午门南侧 |
| 历史锚点 | 午门改端门；宫城名制；由城台北望已消失的宫城 |
| 用户动作 | 到达、登楼、北望、沉默观察、受限回应、下楼、向南穿门、回望 |
| 主要时长 | 约 4 分 35 秒—5 分 05 秒，强依赖登楼、下楼与穿门实测 |
| 固定独白 | 第二段，分城台主体与南侧结尾 |
| 关系阶段 | 现场见证者 → 可以质询的人 → 可能带走记忆的人 |
| 核心问题 | 名分和经典能否自动成为现实秩序？ |

### 2. 为什么必须在这里发生

[A] 建文朝曾将午门改称端门；相关记载见《明太宗实录》卷七九月壬戌朔条。

[B] 更名不是孤立的文字游戏，而是方孝孺等人依经典制度重整宫门名制的一部分。

[C] 午门同时是物理边界：城台上可以回望宫城，穿门向南则完成离开。地点本身把“正名”与“离开一个已不存在的秩序”连接起来。

### 3. 历史锚点

#### 午门改端门

- [A] 更名事件可以使用；
- [B] 可作为建文君臣相信礼制、名分与现实秩序相关的证据；
- [D] 不把更名处理成荒唐笑话；
- [D] 不把制度失败简单归因于“改了几个门名”。

#### 齐泰与《周官》讨论

- [A] 《姜氏秘史》附录《齐泰本传》确有齐泰“主征讨之策，命将出师，多其筹划”以及朱允炆“召学士辈讨论周官法度，处便殿，弄柔翰而已”的文字；
- [B] 事件使用只能推出齐泰高度参与军事筹划，以及后出作者如此描述君臣分工；
- [D] 不能说齐泰掌握全部军事；
- [D] 不能把“弄柔翰而已”当朱允炆自述或中性事实。

#### 文楼、武楼与便殿

- [A][B] 文楼、武楼具有临时听政、讨论经史或边事的功能；
- [B] 朱允炆与方孝孺等人在便殿讨论经义，可能延续这种空间功能；
- [B] 有声稿可用“皇帝不会天天待在最大的正殿”“较小的便殿”“我很喜欢”概括正殿—便殿的功能差异与人物倾向，但不得反写成史书逐字记载；
- [待核验] 便殿不能唯一确定为文楼；
- 画面可呈现文、武楼功能区域，台词不说“我当时就在文楼”。

### 4. 叙事任务

这一场不是批判“读书”，而是揭示原则转化失败：

1. 对朱允炆及方孝孺而言，正名、明礼并非装饰，而是政治行动；
2. 经典可以说明秩序应当怎样，却不能自动判断将领是否胜任、战争怎样控制、政策何时止损；
3. 研究层可讨论亲亲、慎刑、宽仁与削藩行动的冲突；有声台词改说“顾念自家亲族、慎用刑罚、宽待别人”；
4. 不杀或少杀的愿望，不能抵消削藩、调兵和战争造成的暴力；
5. 最终责任不能全部交给方孝孺、黄子澄、齐泰或李景隆。

### 5. 午门北侧：进入前

现实任务：

- 确认用户已经到达安全集结点；
- 简短指认“这道门曾被改称端门”；
- 不在此处展开完整背景。

视觉：

- 午门现实立面为主；
- 可用局部文字叠加显示“午门／端门”，但不做游戏式解谜。

声音：

- 20—30 秒场景设定；
- 随即进入登楼安全沉默。

### 6. 登楼：安全沉默

- 停止主要独白；
- 视觉覆盖降到最低或完全关闭；
- 不要求用户看屏幕；
- 不触发互动；
- 只保留必要安全提示。

这段沉默由安全要求决定，同时也是从门下到全景视角的叙事蓄势。

### 7. 城台北望：观察与第二段独白主体

#### 现实层

- 用户看到今日城市、道路、遗址空缺和刚才走过的正中御道方向；
- 现实景观必须持续可辨，不能被复原完全遮蔽。

#### 绘画复原层

- 固定长卷式场景展开奉天门、奉天殿方向及文、武楼等空间；
- 采用笔触、缺笔、淡出或层级透明度标出证据差异；
- 文楼位置不做厘米级断言；
- 不使用照片级拟真。

#### 观察沉默

设置约 10—15 秒无台词观察。

#### 独白主体

人物从城台所见空间谈到：

- 为什么他相信礼制和文字不只是表面；
- 为什么经典和文书不能替代人物判断及军事控制；
- 为什么愿望中的慎杀没有阻止更大暴力；
- 为什么最高责任仍属于自己。

### 8. 受限互动

位置：城台安全平地，或下楼后的安全平地；以现场安全测试决定。

问题：

> [C] 你要问我，为什么急着削藩，还是为什么把经典和文字看得太重？

限制：

- 两条分支均为三句，并在回答后立即合流；
- “急着削藩”支承认危险判断、逐一处置的误判和皇帝下令；“经典和文字”支承认其知识来源及把纸面秩序投射到现实的限度；两支均按 `[B]`；
- 当前两支净字数为 75 字和 98 字，程序应接受时长不等，不得加速长支；
- 不做开放问答；
- 不问游客是否原谅；
- 不竞猜失踪结局。

### 9. 下楼：第二次安全沉默

- 与登楼相同，停止主要视觉与互动；
- 允许少量呼吸声或环境声，不加新知识；
- 若用户行动较慢，系统保持安静，不催促。

### 10. 午门南侧回望：结尾

地点任务：

[C] 用户已经从宫城内部走到门外，又回头看这道真实存在的边界。

人物任务：

- 明确宫城是其出生、成长、执政和统治终结的生活世界；
- 不说自己死在这里；
- 不请求平反；
- 承认游客已经问过一个问题，并允许其离场后继续追问；
- 只请求对方先承认“建文四年不是空白”。

候选连接句：

> [C] 你不必替我辩护。  
> [C] 只请先承认，建文四年不是空白。  
> [C] 离开这里以后，还可以继续问——为什么把事情做成了这样。

### 11. 风险和兜底

- 城台封闭、雨雪、拥挤或台阶危险：改用午门北侧地面北望画面，再从安全通道到南侧；
- 若不能向南穿门：在北侧完成回望替代，但关系推进会减弱，应重新评估路线；
- 登楼和下楼的实际时长若超过预算，不能从总体验时长中删除；
- 若完整路线稳定超过 8 分钟，应调整产品标称时长，或取消完整登楼，不得加速用户。

## 两节点之间的逻辑

| 奉天门 | 午门 |
|---|---|
| 给三篇文章排出次序 | 给宫门和政治关系规定名分 |
| 试图从文字判断一个人 | 试图用经典安排一个世界 |
| 文章、外表和立场不重合 | 原则、执行和后果不重合 |
| 个人判断的局部失败 | 皇权决策的整体责任 |

宫城作为“家”和“存在证明”负责把两者连接为同一个人的处境，而不是增加第三条知识主线。
