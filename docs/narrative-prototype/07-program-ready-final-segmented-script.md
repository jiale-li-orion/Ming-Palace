## 1. 运行总则

### 1.1 角色与系统分工

- 除系统安全提示外，全部叙事有声内容由朱允炆说出。
- 朱允炆只发出与叙事关系直接相关的动作邀请，不承担实时导航、故障说明或客服职责。
- 台阶方向、绕行、危险提醒、触发失败和到位确认由系统层处理。
- 本原型只有固定台词和一次二选一互动，不接入开放问答。

### 1.2 视觉

- 现实景观始终优先。
- 历史画面使用固定绘画化场景、人物图或局部叠加。
- 画面保留笔触、缺笔、淡出和复原边界，不使用照片级拟真。
- 不声称已经完成 AR、SLAM、实时三维定位或厘米级空间对齐。
- 登楼、下楼、复杂路面、拥挤或其他高风险状态中，主要视觉关闭或降至最低。

### 1.3 音频与安全抢占

- 台阶上不播放核心叙事音频，不触发互动。
- 高风险状态可抢占叙事；待用户重新处于安全平地后，从完整句子的边界恢复。
- 用户行动较慢时保持安静，不催促，不加快语速。
- 环境声段不得用背景音乐填满。
- 默认朗读速度为每分钟 200—215 字；每分钟 220 字只作上限。

### 1.4 低存在感界面

正常体验不持续显示按钮。只有定位触发不可用、语音识别失败或需要无障碍操作时，才按需出现：

- “我已到达奉天门”
- “我已到达午门北侧”
- “我已站稳”
- “为什么急着削藩”
- “为什么太看重经典和文字”
- “我已到达午门南侧”

按钮文案属于系统层，不由朱允炆朗读。

## 2. 状态与流程

```text
S01 奉天门北侧固定独白
  ↓
S02A 向南行走：空间与个人关系
  ↓
HOLD_WALK 行走静默／等待到达午门北侧
  ↓
S02B 午门北侧：改名与秩序
  ├─ tower_mode → SAFE_UP 登楼安全静默
  └─ ground_mode → S04_GROUND 地面观察位
  ↓
S04 午门北望：观察静默与固定独白
  ↓
S05 唯一一次互动
  ├─ S05A 为什么急着削藩
  └─ S05B 为什么太看重经典和文字
  ↓
S06 合流与南望
  ├─ tower_mode → SAFE_DOWN 下楼并穿门
  └─ ground_mode → SAFE_CROSS 按批准路线到午门南侧
  ↓
S07 午门南侧回望与结束
```

`tower_mode` 只有在城台开放、天气和人流允许、用户状态适合且现场安全检查通过时启用。

`ground_mode` 只表示程序能够跳过登楼相关内容。当前地面观察点和行走路线尚未完成现场测试，因此它是待验证兜底状态，不是已经发布的等价体验。

## 3. S01｜奉天门北侧：先看不见的奉天殿

### 程序参数

| 字段 | 值 |
|---|---|
| `segment_id` | `S01_FENGTIANMEN_NORTH` |
| 触发 | 用户位于奉天门北侧安全停留点；原型可由开发者或“我已到达奉天门”触发 |
| 用户状态 | 静止、安全、尚未向南穿门 |
| 视觉初态 | 现实遗址；不立即覆盖完整复原 |
| 有声净字 | 189 字 |
| 预计段长 | 57—62 秒，含 5 秒明确停顿 |
| 下一状态 | `S02A_WALK_SOUTH` |

### 视觉与动作

1. 首句播放时保持现实画面。
2. 用户转身北望后，只淡淡标出奉天殿原有方向。
3. 不呈现照片级完整建筑，不让画面暗示殿试发生在奉天门。

### 朱允炆

先不要穿过这道门。

转身，向北看。

你现在站的地方，从前在我的宫城里。

那座殿，你已经看不见了。

奉天殿原在那个方向。

建文二年，我在那里主持殿试。那也是建文朝唯一的一次殿试。

最后，我把胡广定为第一，王艮第二，李贯第三。

王艮的答卷原本排在前面，最后却退了一名。

### 静默

2 秒。

### 朱允炆

为什么？

文章之外，我也看相貌，也看重胡广答卷里对藩王的批评。

我没有只看文章；但这不等于我就能看清一个人。

文字能呈现主张，不能替我验证一个人的才能和品格。

### 静默

3 秒。

### 朱允炆

现在，转回去。

穿过奉天门，向南走。

奉天殿、奉天门、内五龙桥和午门，原本沿着宫城正中的御道，一座接一座排开。

今天，这条东西向的道路横在奉天门和奉天殿旧址之间，把原来相连的宫城空间切开了。

我出生、成长在这座宫城。成为皇帝以前，这里已经是我生活的地方；后来，我在这里登上皇位、处理政事，统治也在这里终止。

继续向南。现在，先不必听我说。

## 6. S02B｜午门北侧：改名与秩序

### 程序参数

|---|---|

| 用户状态 | 静止、安全 |
| 视觉 | 现实午门立面为主；可低密度叠加“午门／端门” |
| 分流 | 安全判定后进入 `tower_mode` 或 `ground_mode` |

### 朱允炆

前面是午门。

我在位时，它曾改称端门。

方孝孺按照《周礼》建议改名，我听从了。

我们想从每天经过的门开始，按《周礼》把谁在什么位置、该守什么规矩重新定下来。

我们相信，这条路最终应当通向大同，通向从宫廷到天下的安宁和睦。

### `tower_mode` 结尾

系统先确认开放台阶和登楼条件，再播放：

**朱允炆**

上楼时只看脚下。

随后进入 `SAFE_UP`。

### `ground_mode` 结尾

不播放“上楼时只看脚下”。系统引导用户前往经现场批准的午门北侧地面观察点，途中不增加人物台词。

向北看。

### 视觉

先出现宫城正中的御道与主要宫殿空间轮廓，再逐层出现奉天殿及两侧建筑。不要立即出现复原人物。

### 朱允炆

先不要听我说。

看一会儿。

### 观察静默

10—15 秒。

### 朱允炆

中间最大的是奉天殿。两侧有楼，右边是文楼，左边是武楼。

皇帝不会天天待在最大的正殿。比起只在奉天殿接受百官朝见，我很喜欢在较小的便殿里，召来学士讨论《周礼》。

和燕王的战事开始以后，怎么调兵、怎么打仗，我多倚重齐泰；我仍在便殿召来学士讨论《周礼》。

文官做的事、武将做的事可以分开；最后的判断，不能分成两个皇帝。

### 静默

2 秒。

### 朱允炆

正确的名字和《周礼》，不能替我判断将帅，也不能替我承担后果。

我下令削夺藩王的权力，拘禁自己的叔伯，也调兵作战。

我一面说，要顾念自家亲族，慎用刑罚，宽待别人，一面让这些行动继续。

这些原则没有阻止战争扩大。

臣子可以提意见、写文书、定计划、领兵出征。让谁去做，什么时候改变做法，什么时候收手，决定仍归我。

我的本意，不能替结果开脱。

### 静默

4 秒。

## 16. S07｜午门南侧回望：存在确认而非平反

现在，停下来。

回头看这道门。

建文四年，这座城失守，我的统治在这里终止。

不必把你刚才走过的路，当作我的逃路。

你也看见了：这不是一片原本就空着的地方。

不必替我辩护，也不必宽恕我的决定。

3 秒。
