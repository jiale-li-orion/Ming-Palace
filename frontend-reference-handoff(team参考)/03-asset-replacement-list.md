# 视觉素材占位与替换清单

## 1. 使用原则

当前参考界面允许使用占位图，但必须保留稳定编号。未来拿到现场照片或分层绘画后，只替换对应资产，不重新定义页面用途。

每个正式素材应记录：

- 输入来源；
- 拍摄或生成机位；
- 可确认结构；
- 可推定结构；
- 艺术处理；
- 禁止补全内容；
- 生成工具与提示词；
- 修改人；
- 商用权状态；
- 版本和日期。

## 3. 当前占位图

`assets/visual-style-placeholder.png`

用途仅限：

- 长卷绘画语气参考；
- 石青、石绿、墨色与朱砂配色参考；
- 页面构图和文字可读性测试；
- 尚未到位素材的明确占位。

禁止：

- 将其称为奉天门或午门固定视点实景；
- 将其称为朱允炆段落的核验复原；
- 从画中具体建筑或人物反推本段史实；
- 直接作为现场发布资产。

## 4. 横屏分层输出要求

午门横屏观察至少输出：

1. 纯现实底图；
2. 空间轮廓透明层；
3. 建筑复原透明层；
4. 人物活动透明层；
5. 无文字合成预览。

所有层必须保持同一机位、同一地平线和同一画布，不允许单独生成后再靠缩放拼接。

## 5. 现场拍摄提醒

- 奉天门北侧向北、午门北侧到达和午门南侧回望使用竖屏机位；
- 午门北望固定观察视点使用横屏机位；
- 城台路线与地面路线需要分别记录机位；
- 拍摄时额外留出字幕、按钮和系统提示的安全空区；
- 记录拍摄点坐标、镜头高度、方向、焦段、天气和人流；
- 不依赖单张“好看”的风景照替代经过核验的固定视点素材。
