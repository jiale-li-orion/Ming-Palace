# 前端视觉与交互说明

## 1. 产品目标

这是一段在南京明故宫遗址现场发生的条件性 6-8 分钟第一人称叙事体验。游客在步行时只能接收少量信息，因此：

- 行进阶段使用竖屏；
- 安全观察阶段使用横屏；
- 现实景观始终优先；
- 导航只在起步、偏航和接近点位时全屏出现；
- 稳定步行时导航退场，只保留整句字幕、音频控制与少量视觉；
- 主要叙事固定，不开放模型自由生成。

## 2. 九张主页面

| 编号 | 页面 | 方向 | 主要用途 |
|---|---|---|---|
| 01 | 欢迎与准备 | 竖屏 | 区域介绍、安全准备、路线可用性与游客自选 |
| 02 | 起步、偏航、接近导航 | 竖屏 | 全屏箭头、小地图与实景地标 |
| 03 | 稳定行走字幕 | 竖屏 | 整句字幕；主动暂停后显示证据入口 |
| 04 | 安全抢占 | 不限 | 危险提示、叙事与互动锁定 |
| 05 | 到达观察点 | 竖屏 | 实景确认、站稳、转横屏 |
| 06 | 现实观察 | 横屏 | 固定视点与界面显隐 |
| 07 | 分层复原 | 横屏 | 现实、线稿、建筑、人物逐层出现 |
| 08 | 一次受限质询 | 横屏 | 两个固定问题、固定回答、南望和继续确认 |
| 09 | 结束 | 竖屏 | 记忆图淡成现实、史料入口与退出 |

## 3. 角色层与系统层

### 朱允炆负责

- 固定第一人称台词；
- 与叙事关系直接相关的观察与动作邀请；
- 两个固定质询分支的固定回答。

### 系统负责

- 定位与“我已到达”兜底；
- 路线可用性、导航和偏航；
- 城台开放、天气与批准路线条件；
- 安全抢占；
- 音频、网络和设备故障；
- 竖屏、横屏切换提示；
- 退出与恢复位置。

朱允炆不承担左右台阶、绕行、错误定位、故障和客服说明。

## 4. 城台路线决策

系统只能判断：

- 城台是否开放；
- 天气、人流和批准路线是否允许；
- 现场是否满足已经定义的安全条件。

系统不能判断：

- 游客的体力；
- 游客是否恐高；
- 游客的行动能力；
- 游客当下是否愿意走台阶。

因此欢迎页必须同时表达：

1. “城台路线当前可用／不可用”；
2. 一个低压力的“不走台阶”入口。

原则：系统决定路线是否可用，游客决定自己是否适合。

```text
SYSTEM_CHECK
  ├─ 城台可用 → USER_ROUTE_CHOICE
  │               ├─ 城台路线
  │               └─ 不走台阶
  └─ 城台不可用 → GROUND_ROUTE
```

## 5. A/B/C 证据语言

A/B/C 不是高、中、低，不得使用绿、黄、红，也不得让视觉权重逐级递减。

| 标签 | 名称 | 对外含义 |
|---|---|---|
| A | 核心史实 | 有核心事实或较硬证据支撑的历史骨架 |
| B | 史料综合 | 由多项材料、解释传统或受控综合形成 |
| C | 空间叙事 | 用于连接今日地点、游客动作和人物关系 |

三个标签的尺寸、颜色、边框、对比度和排列位置必须同等。差异只通过点击后的评级规则上盖层解释。

### 字幕与证据状态

```text
AUDIO_PLAYING
  ├─ 只显示当前整句字幕
  ├─ 首次只提示一次“暂停台词，可以查看本句依据”
  └─ 用户主动暂停 → AUDIO_PAUSED

AUDIO_PAUSED
  ├─ 当前句末显示 A/B/C 与索引号
  ├─ 点击标签或索引 → EVIDENCE_DRAWER
  └─ 恢复播放 → 隐藏 A/B/C

EVIDENCE_DRAWER
  ├─ 显示本句、依据摘要、文献名称与索引
  ├─ 点击 A/B/C → GRADE_RULE_OVERLAY
  └─ 关闭 → AUDIO_PAUSED
```

当前句自然读完但用户没有主动暂停时，不显示证据标记。

## 6. 发现性提示

以下提示各只出现一次：

- “暂停台词，可以查看本句依据。”
- “轻触画面，可以隐藏文字，安静观看。”

以后不重复。所有核心动作只使用单击，不依赖长按、双击或其他隐藏手势。

## 7. 导航状态

### 起步、偏航和接近

- 全屏显示大方向箭头、小地图和地标；
- 接近午门时用固定实景帮助确认位置；
- 偏航属于系统导航状态，不使用安全页黑黄色；
- 偏航立即暂停台词；
- 返回稳定路线并由游客确认后，从完整句子边界恢复。

### 稳定行走

- 地图与方向提示消失；
- 不显示剩余时间和百分比进度；
- 只保留当前整句字幕、音频控制和少量主图。

## 8. 安全抢占

- 登楼、下楼、复杂路面、人流冲突时停止核心台词、复原画面和互动；
- 安全页采用独立的高对比黑黄系统视觉；
- 安全页不会自动恢复；
- 游客到安全平地后主动点击“我已站稳”；
- 恢复从完整句子的边界开始，不截句。

## 9. 横屏观察状态机

以下顺序必须写死，不能由前端自行省略或重排：

```text
观察
  → 界面隐藏
  → 轻触恢复
  → 质询
  → 回答
  → 南望
  → 90 秒无操作
  → 下一次轻触后出现行进询问
  → 再看看
  → 120 秒后最后提示
  → 此后不再主动提示
```

### 强制规则

1. 自动提示只在用户处于安全平地时触发。
2. 90 秒到达时不立即弹窗；游客下一次轻触后才显示行进询问。
3. 游客选择“再看看”后，120 秒再显示最后一次提示。
4. 最后一次提示之后不再主动提示。
5. 不强制退出横屏。
6. 横屏期间旋转手机不能直接进入行走。
7. 必须先确认“继续行进”，再显示“请将手机转回竖屏”。
8. 若用户未确认继续，设备方向变化不改变体验状态。

### 界面显隐

```text
CHROME_VISIBLE
  ├─ 首次显示一次“轻触画面，可以隐藏文字，安静观看”
  └─ 单击空白 → CHROME_HIDDEN

CHROME_HIDDEN
  ├─ 只保留极低存在感的安全退出入口
  └─ 单击空白 → CHROME_VISIBLE
```

## 10. 七类异常与兜底

### F01 定位权限被拒绝

- 解释定位只用于点位触发；
- 提供“去设置”；
- 提供“使用手动到达”；
- 不阻断已经下载的本地内容。

### F02 定位触发失败

按当前段落显示：

- 我已到达奉天门；
- 我已到达午门北侧；
- 我已站稳；
- 我已到达午门南侧。

### F03 手机锁定竖屏

- 提示关闭方向锁；
- 若无法处理，进入竖屏固定画面版本；
- 竖屏版本不得伪装为实时 AR 或城台横屏实景。

### F04 音频加载或耳机异常

- 暂停主线；
- 保留完整字幕；
- 提供“重新加载音频”；
- 提供“继续无声体验”；
- 提供退出。

### F05 城台临时关闭

- 城台路线立即置为不可用；
- 切换到地面路线；
- 不播放登楼或下楼角色台词；
- 地面观察图必须明确为地面固定视点。

### F06 网络不可用

- 已下载本段时提示“本地内容可继续”；
- 继续主线、定位兜底与本地证据摘要；
- 暂时禁用需要联网的书影、外部链接和扩展内容。

### F07 主动退出后的恢复

至少记录：

- 最后完成的 `segment_id`；
- `tower_mode` 或 `ground_mode`；
- 所选质询分支；
- 是否已经确认继续行进；
- 上次退出是否发生在安全抢占中。

恢复只能发生在完整段落边界，不能从半句话、台阶中或危险状态中自动继续。

## 11. 视觉规范

- 现实页面明亮淡雅，偏《清明上河图》的空间长卷感；
- 宣纸米白、石青、石绿、墨黑为主体，朱砂只作行动与重点；
- 朱允炆只出现声音、字迹、衣袍、手、背影或空位，不画写实完整肖像；
- 复原层保留笔触、缺笔、留白与淡出，不制造照片级历史现场；
- “便殿”不得被定位为文楼、省躬殿或其他确定建筑。

## 12. 实现验收清单

- [ ] 竖屏和横屏状态均可在常见手机比例下阅读；
- [ ] 稳定行走页不显示剩余时间；
- [ ] 两项首次提示分别只出现一次；
- [ ] A/B/C 等权且不使用红黄绿层级；
- [ ] 横屏不能因设备旋转直接进入行走；
- [ ] 确认“继续行进”后才提示转回竖屏；
- [ ] 所有自动横屏提示只在安全平地触发；
- [ ] 偏航与安全抢占均暂停台词；
- [ ] 网络不可用时已下载本地内容可继续；
- [ ] 恢复位置记录到完整段落边界。
